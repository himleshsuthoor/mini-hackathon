# StudyBuddy - Student Task Manager

Live demo: (add after deployment) | Demo video: (add after recording)

## Problem
University students manage assignments, lab tasks, quizzes, exams and personal study goals across several subjects at the same time. Most of them keep track in chat messages, notebooks or memory, so deadlines get missed and it is unclear what to work on first. This leads to last-minute work and avoidable loss of marks.

## Solution and features
StudyBuddy is a simple web app where a student adds academic tasks with a subject, deadline and priority, sees them automatically sorted by what matters most, and tracks progress as tasks get completed.

1. Add a task with title, subject, deadline and priority.
2. View tasks sorted by priority and then deadline, with a subject filter.
3. Mark tasks as done or delete them, and see a progress summary.
